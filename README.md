# Squadron

A browser-based 2D game built with Vue 3 and Phaser. The game canvas is fixed at
1024 × 768 pixels and centered in the page.

## Getting started

Requires Node.js 22 or later.

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and create a production build, or `npm run test`
to run the test suite.

See [the documentation](docs/README.md) for the project structure and game
window details.
