# Squadron

A browser-based 2D game starter built with Vue and Phaser. The game canvas is fixed at 1024 × 768 pixels and centered in the page.

## Get started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`; run the starter checks with `npm test`.

See [`docs/README.md`](docs/README.md) for the project structure, game sizing, and development notes.
