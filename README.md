# Squadron

A browser-based 2D game starter built with Vue 3 and Phaser. The game canvas is fixed at 1024 × 768 and centered in the page.

## Get started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. See [`docs/README.md`](docs/README.md) for the project structure, game setup, and production build instructions.
