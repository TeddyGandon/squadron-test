# Squadron

A browser-based 2D game starter built with Vue 3 and Phaser 3. The game canvas is fixed at 1024 × 768 and stays centered on the page.

## Get started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite to play. To create a production build, run `npm run build`.

See [`docs/README.md`](docs/README.md) for the game structure, fixed-canvas behavior, and development notes.
