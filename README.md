# Squadron

A browser-based 2D game starter built with Vue 3 and Phaser 3. The game canvas is fixed at 1024 × 768 and centered in the page.

## Get started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm run build` to type-check and create a production build, or `npm test` to run the starter tests.

See [the project documentation](docs/README.md) for the architecture and game setup.
