# Squadron

A browser-based 2D game starter built with Vue and Phaser. The game canvas is
1024 × 768 pixels and remains centered on the page without resizing.

## Get started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite to see the starter scene. Run `npm run build`
to type-check and create a production build.

See [the documentation](docs/README.md) for the game setup and project layout.
